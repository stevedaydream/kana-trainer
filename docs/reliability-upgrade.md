# 2026-10-29 可靠性與本地新聞管線改善

已在 `codex/reliability-local-news` 實作；不引入使用者端框架、建置程序或帳號系統。

## 行為修正

- 考試延遲回呼由畫面 scope 管理；退出即取消。計時採截止時間，結算只能執行一次。
- 存檔加入 schemaVersion=2；啟動及匯入共用完整驗證。無效匯入不先修改狀態，匯入前另存原進度並提供還原按鈕。非同步儲存依序寫入，失敗顯示備份提示；啟動發現原檔損壞時不覆寫原檔。
- 新聞進度以 pack.id 隔離。舊日期鍵只在當日唯一文章時遷移；多包日期有歧義時重新練習，不把完成度複製給所有文章。
- 口說解鎖使用學習者自選程度；文章的 N1 標記不再等同使用者程度。
- 麥克風延遲取得權限後若已離開，立即釋放串流；錄音結束清理 tracks／Object URL，使用實際 MIME type。
- 書寫採 pointer capture，處理取消、失焦與多指干擾，移除逐字累積的全域 pointerup listener。
- 首頁保留繼續學習／今日複習入口，其餘模式收在原生 disclosure；翻牌支援 Enter／Space，級別與計畫改用原生 button，補焦點、日文語言標記與低動態偏好。
- 116 張缺圖補為原創簡筆 SVG，全部 208 音有本機圖片；隨機單詞與預設聯想圖不同時加註圖像對應詞。

## PWA 與內容發布

版本化 shell（HTML/CSS/JS）一起快取，透過使用者選擇更新；索引與題庫獨立 network-first，5 秒逾時回同類快取；每篇文章為獨立含雜湊檔案，cache-first，最近 3 篇安裝時預快取。缺少資料不回 HTML，快取寫入以 waitUntil 保活，只清理本專案的舊快取。SVG 預快取，避免初次安裝下載全部既有大圖。

RSS → 時效與重複篩選 → Port Monitor Chat Completions → 失敗時 Gemini 備援 → 嚴格驗證 → 獨立文章與索引原子發布。來源網址及時間由抓取程式寫入，不信任模型生成的出處。新內容讀音、語言、題型、互異選項與答案索引必須通過；既有三份全部選項重複的題目已修復。舊新聞不回溯宣稱已核實來源。

新聞與辭庫工作流程共用同一分支發布鎖，輸入經環境變數傳遞；一般 push/PR 加入 CI。台灣日期與每日 05:00 排程對齊。更新後的排程為本地優先、Gemini 備援；本地未配置、離線或產出不合格時明確標記備援，兩者皆失敗則不發布。

## 驗證與限制

`npm run validate`、`npm test`、`npm run test:e2e`。回歸案例覆蓋退出考試、截止時間、匯入原子性、存檔寫入次序、新聞進度隔離、舊鍵遷移、本地 API 合約、RSS 時效、完整模擬產生管線、離線啟動及麥克風權限競態。瀏覽器為 Windows Chrome 的手機與桌面 viewport；非實體手機，也未宣稱已驗證 Safari／實體錄音。

本地閘道現況與啟用步驟見 [接入研究](local-ai-news-integration.md)。尚需 Port Monitor 桌面建立專案背景 key、Tailscale 可達入口與 CI 身分，才能實測真模型生成。Schema、來源與時效檢查不等同語言／事實真確性審稿；模型改寫仍可能有語意或讀音錯誤。

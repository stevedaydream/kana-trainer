# 配圖下載清單

**目前缺圖：116 張**

> 由 `data/levels.js` 自動產生。圖檔命名規則：**檔名 = img 鍵 + `.png`**，放入 `img/`。
> 缺圖不影響上線（自動退回內建 SVG / emoji）。
>
> **建議來源**：[いらすとや](https://www.irasutoya.com/) — 以「日文搜尋關鍵字」查詢後下載頁面上的 PNG。
> 找不到的可用可愛簡筆插畫風自行生成：白底、單一主體、正方形、≥300×300、PNG。
>
> ⚠ いらすとや 圖片需自行下載保存、禁止外連；同一商用作品上限 20 張。若 repo 為公開，建議圖片僅留本機。
>
> 📌 **補圖後請把該列從本清單刪除**，並跑 `node scripts/check-image-list.mjs` 對帳（會檢查本清單、`img/`、`data/levels.js` 三方是否一致，並校對上方的缺圖張數）。

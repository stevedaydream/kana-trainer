# 五十音練習器（PWA）

翻牌提取練習 × 錯題加權 × 十級解鎖的五十音練習器。純 HTML/CSS/Vanilla JS，零框架、零建置、零外部 CDN；可安裝為 PWA 離線使用，也可直接雙擊 `index.html`（file://）運作。

## 使用方式

- **本機直接開**：雙擊 `index.html` 即可（file:// 下自動略過 Service Worker，功能完整）。
- **PWA 安裝**：以任一靜態伺服器託管（例如 `npx serve` 或 GitHub Pages），瀏覽器網址列會出現「安裝」按鈕；安裝後可離線使用。

## 玩法

1. **翻牌練習**（每級 Part 1 平假名 / Part 2 片假名 / Part 3 混合）：亮假名 → 先在心裡唸 → 點卡揭曉（羅馬音＋字源＋圖＋單詞＋播音）→ 自評「✓記得 / ✗忘了」。
2. **錯題加權**：✗ 出現機率 ×4（上限 16）；✓ 一次減半、連對兩次歸 1。首頁「弱項榜」顯示最弱的假名。
3. **考試**（Part 4，60 秒）：聽選／讀選／平片配對 三題型隨機，答錯播正確音並餵入權重。答對 ≥ 12 題解鎖下一級。
4. **熱身**：級別頁可勾選「開始前每字播放跟讀一輪」，可隨時跳過。

## 學習優化（認知神經科學導向）

首頁提供以下模式，把間隔重複、交錯練習、辨別學習、產出型回憶與動機機制整合進日常迴圈：

- **📅 今日複習（FSRS-lite 間隔重複）**：以 DSR 模型（難度／穩定度／可提取度、目標留存 90%、`R = exp(ln0.9·t/S)`）為每個假名排程，只在「記憶正要淡去」時把到期假名推給你複習；答錯當日重練，答對依穩定度拉長間隔（每日上限 40 張以控管認知負荷）。
- **🎯 總複習 / 挑戰**：跨級交錯練習——自選範圍（1–5／6–10／11–14／全部）× 種類（平／片／平+片）× 模式（翻牌複習或 60 秒挑戰），強化編碼變異與提取。
- **🔀 易混淆特訓**：針對 シ/ツ/ソ/ン、ね/れ/わ、は/ほ/ま… 等形近字，考試選項優先塞入形近干擾，逼你「注意到差異」（Noticing the Gap）。
- **✍️ 產出型回憶**：挑戰考試可開「輸入模式」，鍵入羅馬音（容錯：`shi/si`、`tsu/tu`…）而非選擇題，強化較深的句法／產出編碼。
- **去中介化**：某假名穩定度 ≥ 21 天視為精熟，翻牌時字源聯想預設收合（可點開），逼你直接提取而非依賴聯想拐杖。
- **🔊 聽音辨形 / 🗣️ 跟讀練習**：音先於形的聽力優先訓練與影子跟讀（聽→哼→影子）；無語音環境自動隱藏。聽音辨形可選「平主片副／片主平副」，揭曉時同時對照同音的平假名與片假名，一次綁定「音 → 兩套字形」。
- **⚙️ 語音設定**（首頁右上）：自選系統日語語音，並提供四種人格——可愛女聲／性感女聲／陽光男聲／低沉男聲——加「自訂」音高（pitch）與語速（rate）滑桿、試聽，設定持久化。人格依語音名稱啟發式自動挑選相符性別的語音。
  > 限制：採瀏覽器內建 Web Speech API，只能使用**裝置已安裝**的日語語音、僅能調整音高/語速，無法合成全新音色；「性感」等為音高/語速的近似，實際可用語音因作業系統/瀏覽器而異（部分環境可能沒有日語語音，此時以預設音高/語速朗讀）。
- **🔥 每日目標 / 連續天數 + 課後總結**：呼應 24 小時鞏固循環，追蹤連續天數、每日題數與各次練習的正確率／最弱假名。
- **💪 弱項鍛鍊 + ★ 星號**：弱項榜依「權重 ×N ・ 忘記次數（`srs.lapses`）・ 星號」排序；翻牌揭曉卡可按「☆ 標記易忘」把任意假名手動加入弱項池；弱項鍛鍊集中練習這些字。
- **🎲 每日隨機考**：從已解鎖級別隨機抽 60 題（聽選／讀選／配對），≥ 45 題及格，記錄最佳成績。
- **📋 今日計畫（App 內提醒）**：依「學習強度」自動生成每日待辦清單並提醒未完成——
  - 高強度：每天 2 級 ＋ 弱項鍛鍊 ＋ 每日隨機考 ×2
  - 一般（預設）：每天 1 級 ＋ 弱項鍛鍊 ＋ 每日隨機考 ×1
  - 休閒：每 2 天 1 級（與弱項交錯）＋ 每日隨機考（可取消）
  - 於 ⚙️ 設定 → 學習強度 切換；清單跨日自動重置。
- **✍️ 書寫練習**：田字格 canvas 描紅（淡色範字）＋自由描寫（觸控/滑鼠），清除／完成換字；不做手寫辨識。
- **⚙️ 設定中心**（首頁右上）：整合「學習強度」「語音」「備份還原」三區。
  - **語音**：自選系統日語語音 ＋ 四種人格（可愛女／性感女／陽光男／低沉男）＋ 自訂音高/語速 ＋ 試聽。
    > 限制：採瀏覽器內建 Web Speech API，只能用**裝置已安裝**的日語語音、僅能調音高/語速，無法合成新音色；「性感」等為近似，可用語音因系統而異。
  - **備份還原**：把全部進度（解鎖、SRS、錯題/忘記次數、星號、每日計畫、語音設定…）**匯出成 JSON 檔**或複製，並可從檔案/貼上**還原**——這是跨瀏覽器與未來 APK 之間搬遷進度的方式（純離線、無雲端帳號）。

- **📰 每日新聞（AI 新聞模組）**：以「新聞式分級短文」練聽/讀/說五技能，內容與程式分離（`data/news.js` 是唯一內容來源，程式只渲染；朗讀用本機 TTS 合成，離線可用）。**新聞包會累積成歷史**，首頁 📰 進去是列表，可回頭重讀任一天（可重複學習）。
  - **📻 聽力**（逐句先聽後揭曉）→ **✍️ 聽寫**（聽打字、容錯比對）→ **📖 閱讀**（中/英/振假名切換、點單字看解釋、文法重點）→ **📝 小考 5 題**（≥3 及格）→ **🗣️ 口說（七步跟讀）**。
  - **輸入先於輸出**：口說採影子跟讀七步（音韻浸潤→語音標記→視讀哼唱→盲聽節奏→語意融合→**錄音診斷**→脫稿演繹）；第 6 步用 `MediaRecorder` 錄音回放（留本機、無麥克風時優雅降級）；**第 7 步「脫稿」需先完成聽力＋聽寫＋小考(≥3) 才解鎖**（或程度 N3 以上），避免初階硬輸出導致石化。
- **🔤 每音讀音辭庫（×5，翻牌隨機抽詞）**：`data/wordbank.js` 為每個假名提供多個單詞，練習揭曉時**隨機抽一個**（解決「每次讀音都同一個單字」）；某假名若辭庫沒有就退回題庫單一詞。內建第 1 級（あ行）範例，其餘由自動化補齊。

### 每日自動化（Gemini，需自備金鑰）

AI 只在**離線管線**跑、不進瀏覽器（同題庫分離精神）。設定：repo Settings → Secrets → 新增 `GEMINI_API_KEY`（可另設 variable `GEMINI_MODEL`，預設 `gemini-2.5-flash`）。

- **每日新聞**：`.github/workflows/daily-news.yml`（cron 每日；也可手動觸發選難度/主題）→ `scripts/generate-news.mjs` 讀真新聞→**重製摘要**分級包→驗證→累積進 `data/news.js`（保留最近 60 則）。
- **讀音辭庫 ×5**：`.github/workflows/wordbank.yml`（手動觸發一次）→ `scripts/generate-wordbank.mjs` 為每音補 5 詞→`data/wordbank.js`。
- 本機亦可跑：`GEMINI_API_KEY=xxx node scripts/generate-news.mjs`；離線驗證水路用 `--mock`。
- 內容驗證：`node scripts/validate-news.mjs`、`node scripts/validate-wordbank.mjs`。授權界線（只重述事實、原創改寫、不逐字複製、標出處）見 `docs/ai-news-module-design.md`。

所有進度（含 SRS 排程、連續天數、各範圍最佳成績、星號、學習強度計畫、新聞輸入完成度）一起持久化，舊存檔自動相容。

## 檔案結構

```
kana-trainer/
├─ index.html            # 主程式（UI + 邏輯，不含任何題庫資料）
├─ data/levels.js        # 題庫外掛檔（唯一資料來源；換題庫只換這個檔）
├─ img/                  # 配圖（檔名 = 題庫 img 鍵 + .png；缺檔自動退回 SVG/emoji）
├─ scripts/validate.mjs  # 題庫驗證：node scripts/validate.mjs
├─ manifest.webmanifest  # PWA manifest
├─ sw.js                 # Service Worker（app shell 預快取 + 配圖 runtime cache）
├─ icon.svg              # 應用圖示（img/icon-192.png、img/icon-512.png 為 PNG 版）
└─ project.md            # 專案規格
```

## 測試用 URL 參數

- `?unlock=all` — 解鎖全部級別（測試後門）。
- `?notts=1` — 模擬無語音環境：靜音運作、考試剔除聽選題。

## 題庫驗證

```
node scripts/validate.mjs
```

檢查欄位齊全、羅馬音特例（し=shi、ち=chi、つ=tsu、ふ=fu、を=o、ん=n、じ/ぢ=ji、づ=zu、しゃ=sha、ちゃ=cha、じゃ=ja…）、pair 平片雙向對稱、img 鍵全域唯一、每級數量正確，並列出缺圖清單（缺圖可上線，會自動退回）。羅馬音表與級別數量表皆為資料驅動。

## 級別總覽（14 級・208 音）

| 階段 | 級別 | 內容 |
|---|---|---|
| 第一階段（清音） | 1～10 | あ行～わ行・ん，每級 5 音（や行/わ行 3 音） |
| 第二階段（濁音） | 11 | 濁音 が・ざ・だ行（15 音） |
| 第二階段（濁音/半濁音） | 12 | 濁音 ば行 ＋ 半濁音 ぱ行（10 音） |
| 第二階段（拗音） | 13 | 拗音 I：き・し・ち・に・ひ 系（15 音） |
| 第二階段（拗音） | 14 | 拗音 II：み・り・ぎ・じ・び・ぴ 系（18 音） |

拗音為多字假名（如 `きゃ`），卡片與考試選項字級自動縮小；濁音/拗音的 `origin` 欄改為規則說明格式（如「か ＋ 濁點（゛）→ が」「き ＋ 小さい ゃ → きゃ」）。詞首罕見的 ぢ／づ／ヂ／ヅ 以白名單處理（單詞改用含該假名的詞）。
